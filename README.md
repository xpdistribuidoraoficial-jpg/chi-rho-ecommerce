# Chi Rho E-commerce V1

Projeto estático em HTML/CSS/JS pronto para GitHub + Vercel.

## Estrutura
- index.html
- style.css
- script.js
- assets/logo-chi-rho.png
- assets/banner-home.png

## Como publicar
1. Crie um novo repositório no GitHub, sugestão: `chi-rho-ecommerce`
2. Faça upload de todos os arquivos mantendo a pasta `assets`
3. Na Vercel, clique em Add New Project
4. Importe o repositório
5. Framework Preset: Other
6. Root Directory: ./
7. Deploy

Não é necessário Build Command.
